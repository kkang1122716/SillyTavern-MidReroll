# ✂️ Mid Reroll (중간 리롤)

AI 답변이 일부만 아쉬울 때 쓰는 실리태번 확장이에요. 두 가지 방식이 있어요.

- **✂ 여기서부터 다시 쓰기**: 자를 지점을 고르면 그 앞은 그대로 두고 뒤만 새로 써요. 자른 자리에 전개 지시를 주거나 내 반응(대사·행동)을 끼워넣을 수도 있어요.
- **🔁 부분만 갈아끼우기**: 중간의 문단이나 문장만 골라 그 부분만 새로 써요. 원래 글과 새 글을 나란히 비교하고, 마음에 들면 그 자리에 바로 갈아끼워요.

## 설치

실리태번 → 확장 프로그램(블록 아이콘) → **Install extension** 에 아래 주소를 넣고 설치하세요.

```
https://github.com/kkang1122716/SillyTavern-MidReroll
```

## 여는 방법

- 마지막 AI 답변 위쪽 버튼 줄의 ✂ 가위 버튼을 누르세요. 설정에서 `···` 메뉴 안으로 옮길 수도 있어요.
- 채팅 입력창 옆 마법봉(확장) 메뉴의 **중간 리롤**을 눌러도 돼요.
- 채팅 입력창에 `/midreroll`을 쳐도 열려요.

> 테마나 다른 확장이 `···` 메뉴를 바꿔 놓아서 버튼이 안 보이면, 설정의 "✂ 버튼 위치"를 **메시지 위 버튼 줄에 바로**로 두세요.

## 사용법

1. 창 맨 위에서 방식을 고르세요. 처음에 보일 방식은 설정에서 정해요.
2. 위치나 범위를 고르세요.
   - 다시 쓰기: 누른 문단부터, 또는 드래그를 시작한 글자부터 끝까지 새로 써요.
   - 갈아끼우기: 문단을 누르면 그 문단을 골라요. 다른 문단을 더 누르면 그 사이까지 넓어지고, 드래그하면 드래그한 글자만 골라요.
   - 채팅에서 미리 드래그해 두고 버튼을 눌러도 그 위치가 자동으로 잡혀요.
3. 필요하면 **전개 지시**를 적거나 프리셋 버튼으로 넣으세요. 이번 생성에만 한 번 쓰이고 채팅에는 남지 않아요.
4. 다시 쓰기에서는 **끼워넣을 내용**도 넣을 수 있어요.
   - 답변 안에 넣기: AI 답변 속에 그대로 들어가고, AI가 그 뒤를 이어 써요.
   - 유저 메시지로 따로: 내 메시지가 따로 생기고, 그다음에 AI가 새 답변을 써요.
5. **다시 쓰기**를 누르세요.
   - 갈아끼우기는 비교 창이 떠요. 새 글은 직접 고칠 수 있고, **다시 생성**으로 다른 결과를 받아 볼 수도 있어요.

같은 메시지에서 창을 다시 열면 직전에 고른 위치와 입력한 내용이 그대로 채워져 있어요.

## 번역 (창 안에서만)

외국어로 채팅할 때 확인용으로 쓰는 기능이에요. **번역은 창 안에서만 보여 주고, 채팅에는 원문이 그대로 남아요.**

- 창의 **번역 같이 보기**를 누르면 각 문단 아래에 번역이 붙어요. 번역 문단을 눌러도 그 문단이 골라져요.
- 다시 쓰기 결과가 다른 언어면 **새로 쓴 부분 확인** 창이 떠요. 이 창에서 번역해 보고, 그대로 두거나, 되돌리거나, 다시 쓸 수 있어요. 언제 띄울지는 설정에서 정해요.
- 갈아끼우기 비교 창에서도 원래 글과 새 글을 각각 번역해 볼 수 있어요.
- 번역 엔진은 **구글 번역 (무료)** 와 **AI 번역** 중에서 골라요. AI 번역은 현재 연결, 저장 프로필, 커스텀 중 하나로 보내요.
- 번역할 때는 **그 글만** 보내요. 채팅 기록이나 캐릭터 정보는 보내지 않아요.
- 번역 결과는 기본으로 기억하지 않아요. "번역 결과 기억하기"를 켜면 이 탭에만 잠깐 기억해요. 채팅 파일이나 서버에는 저장하지 않아요.

**채팅 화면에 번역문을 보여주는 번역 확장을 같이 쓸 때**
- 채팅에 번역문이 보이는 상태에서 드래그해도, 같은 문단의 원문 위치로 맞춰 줘요. 이때는 문단 단위로 맞춰요.
- 창의 "번역 같이 보기"는 그 확장이 이미 만든 번역을 그대로 써서 따로 요청하지 않아요. 문단 수가 맞을 때만 그래요.
- 다시 쓰거나 갈아끼운 뒤에는 옛 번역을 떼고 "메시지가 바뀌었다" 신호를 보내요. 그래서 번역 확장이 새 글을 다시 번역해요.

## 다른 확장(기억·상태창 등)과 같이 쓸 때

갈아끼운 뒤에는 실리태번에서 연필로 고친 것과 같은 **"수정됨"** 신호를 보내요.
기억이나 상태창 확장 대부분은 이 신호로 바뀐 글을 다시 읽어요.

다만 **새 답변일 때만 도는 기능**은 다시 돌지 않아요. 답변 점검, 실시간 상태 갱신, 보이스 자동 재생 같은 것들이에요.
이런 기능도 다시 돌리고 싶으면 설정의 **갈아끼운 뒤 다른 확장에 "새 답변"으로 알리기**를 켜세요.
대신 확장에 따라 같은 답변을 한 번 더 처리해서 모델 호출이 늘 수 있어요. 그래서 기본은 꺼져 있어요.

- 갈아끼울 글을 만드는 동안에는 "조용한 생성"을 써요. 대부분의 확장은 이걸 무시하니까 생성 도중에 끼어들지 않아요.
- **✂ 여기서부터 다시 쓰기**를 현재 연결로 쓸 때는 실리태번의 이어쓰기를 그대로 써요. 그래서 평소 이어쓰기처럼 "새 답변(이어쓰기)" 신호가 나가요.

## 전개 지시 언어

모델은 보통 **영어 지시**를 가장 잘 따라서 기본은 English예요. 中文, 日本語, 한국어로도 바꿀 수 있어요.

- 프리셋과 지시문은 언어마다 따로 저장돼요.
- 한국어로 적은 지시나 새로 만든 프리셋은 고른 언어로 **자동 번역**해서 보내요. 설정에서 끌 수 있어요.

## 결과 처리: 새 스와이프 vs 덮어쓰기

| | 새 스와이프 | 덮어쓰기 |
|---|---|---|
| 원본 | 이전 스와이프로 남아요 (← 로 돌아가기) | 메시지 안에 백업돼요 (창에서 "↩ 덮어쓰기 전 원본으로 되돌리기") |
| 결과 | 새 스와이프로 추가돼요 | 지금 보이는 답변이 바뀌어요 |

기본은 다시 쓰기가 새 스와이프, 갈아끼우기가 덮어쓰기예요. 창에서 매번 바꿀 수도 있어요.
두 방식 모두 AI에게 보내는 내용은 똑같고, 원본을 어디에 보관하느냐만 달라요.

## 보낼 프롬프트 확인

창 아래쪽의 **📋 보낼 프롬프트 확인**을 누르면 지금 고른 설정으로 실제로 보낼 프롬프트를 미리 만들어서 보여줘요. 이때 생성은 하지 않아요.

- **캐릭터 카드:** 설명, 성격, 시나리오, 예시 대화, 캐릭터 노트 등이 들어갔는지 보여줘요.
- **페르소나:** 설명이 들어갔는지 보여줘요.
- **월드인포:** 켜져 있는 로어북마다 몇 개 항목이 들어갔는지, 그리고 항목 이름을 보여줘요.
- **확장이 끼워넣은 내용:** 요약, 작가 노트, 기억 확장, 이번 지시 등이 들어갔는지 보여줘요.
- **전체 크기:** 대략 몇 토큰인지, 채팅 기록이 몇 개 들어갔는지 보여줘요.
- **전체 프롬프트:** 원문을 그대로 보고 복사할 수 있어요.

정리하면, 생성할 때는 **평소 생성과 똑같이** 카드, 페르소나, 월드인포, 프리셋, 채팅 기록이 다 들어가요. 번역할 때만 번역할 글 하나만 보내요.

## API 설정

- **현재 연결**: 평소처럼 실리태번이 생성해요.
- **실리태번 저장 프로필**: 연결 관리자에 저장해 둔 프로필로 보내요.
- **커스텀**: OpenAI 호환 주소, 모델, 키를 직접 넣어요. 키는 서버가 아닌 **이 브라우저에만** 저장돼요.

저장 프로필과 커스텀도 캐릭터 카드·월드인포·프리셋이 들어간 **지금 채팅의 프롬프트를 그대로** 쓰고, 보내는 곳만 바뀌어요.

## 알아둘 점

- **마지막 AI 답변**에서만 쓸 수 있어요.
- 문장 중간에서 자르고 끼워넣으면, 열려 있던 `*` 나 `"` 를 자동으로 닫아 줘요.
- 모델이 앞부분을 다시 쓰면 자동으로 잘라내요. 고급 설정에서 끌 수 있어요.
- 새로 써진 내용이 하나도 없으면(에러, 빈 응답) 자동으로 원래대로 되돌려요.
