# ✂️ Mid Reroll (중간 리롤)

AI 답변이 앞부분은 마음에 드는데 뒷부분만 아쉬울 때 쓰는 실리태번 확장이에요.
**자를 지점을 고르면** 그 앞은 그대로 두고, 그 뒤만 새로 써 줍니다.
자른 자리에 **원하는 전개 지시**를 주거나 **내 반응(대사·행동)을 끼워넣을** 수도 있어요.

## 설치

실리태번 → 확장 프로그램(블록 아이콘) → **Install extension** 에 아래 주소를 넣고 설치하세요.

```
https://github.com/kkang1122716/SillyTavern-MidReroll
```

## 사용법

1. 마지막 AI 답변의 `···` 메뉴에서 ✂️ 가위 버튼을 누르세요. 채팅 입력창에 `/midreroll`을 쳐도 돼요.
2. 다시 쓰기를 시작할 위치를 고르세요.
   - **문단 클릭**: 누른 문단부터 끝까지 새로 써요.
   - **드래그**: 드래그를 시작한 글자 위치부터 새로 써요. 채팅에서 미리 드래그해 둔 뒤 버튼을 눌러도 그 위치가 자동으로 잡혀요.
3. 필요하면 아래 두 칸을 채우세요. 둘 다 비워 두면 그 지점부터 그냥 다시 써요.
   - **끼워넣을 내용**: 내가 쓴 대사나 행동이에요.
     - 답변 안에 넣기: AI 답변 속에 그대로 들어가고, AI가 그 뒤를 이어 써요.
     - 유저 메시지로 따로: 내 메시지가 따로 생기고, 그다음에 AI가 새 답변을 써요.
   - **전개 지시**: 이번 생성에만 한 번 쓰이고 채팅에는 남지 않아요. 아래 프리셋 버튼으로 바로 넣을 수 있어요.
4. **다시 쓰기**를 누르세요.

같은 메시지에서 창을 다시 열면, 직전에 고른 위치와 입력한 내용이 그대로 채워져 있어요.

## 결과 처리: 새 스와이프 vs 덮어쓰기

| | 새 스와이프 (기본) | 덮어쓰기 |
|---|---|---|
| 원본 | 이전 스와이프로 남아요 (← 로 돌아가기) | 메시지 안에 백업돼요 (창에서 "↩ 덮어쓰기 전 원본으로 되돌리기") |
| 결과 | 새 스와이프로 추가돼요 | 지금 보이는 답변이 바뀌어요 |

**두 방식 모두 AI에게 보내는 내용은 똑같아요.** 다른 스와이프는 프롬프트에 들어가지 않거든요.
바뀌는 건 원본을 어디에 보관하느냐뿐이에요. 결과가 앞부분을 반복하는 건 방식 때문이 아니라 모델의 이어쓰기 습관 때문이에요.
그래서 **모델이 앞부분을 다시 쓰면 자동으로 잘라내는** 기능을 넣어 두었어요. 고급 설정에서 끌 수 있어요.

## API 설정

- **현재 연결**: 평소처럼 실리태번이 생성해요. 스트리밍, 정규식 스크립트, 정지 버튼이 다 그대로 동작해요.
- **실리태번 저장 프로필**: 연결 관리자에 저장해 둔 프로필로 보내요.
- **커스텀**: OpenAI 호환 주소, 모델, 키를 직접 넣어요. 키는 서버가 아닌 **이 브라우저에만** 저장돼요.

저장 프로필과 커스텀도 캐릭터 카드·월드인포·프리셋이 들어간 **지금 채팅의 프롬프트를 그대로** 쓰고, 보내는 곳만 바뀌어요.
다만 이 두 방식은 실리태번 생성 과정을 거치지 않기 때문에, 정규식 스크립트(AI 출력)는 결과에 자동으로 적용되지 않아요.

## 알아둘 점

- 이어쓰기 원리상 **마지막 AI 답변**에서만 쓸 수 있어요.
- 문장 중간에서 자르고 끼워넣으면, 열려 있던 `*` 나 `"` 를 자동으로 닫아 줘요.
- 새로 써진 내용이 하나도 없으면(에러, 빈 응답) 자동으로 원래대로 되돌려요.
